# Community code of conduct

Help make this project welcoming to people with different experience levels and backgrounds.

- Be respectful and assume good intent. Critique ideas and code, not people.
- Give specific, constructive feedback and useful reproduction steps.
- Respect privacy. Do not post credentials, private images, personal account details, or someone else's identifying information.
- Do not harass, threaten, discriminate, spam, or repeatedly disrupt discussions.
- Respect maintainers' and contributors' time and boundaries.

These expectations apply to repository issues, pull requests, discussions, and other project-managed spaces. Maintainers may edit or remove inappropriate content, close disruptive conversations, or restrict participation. Enforcement should consider the severity and repetition of the behavior.

For moderation concerns, use GitHub's reporting tools or notify a repository maintainer without repeating private information publicly. For software vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of posting sensitive details in an issue.
